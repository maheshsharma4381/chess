# AGENTIC SKILLS & WORKFLOW EXECUTION MANDATE
You have access to powerful installed agentic skills in this environment. For every task, phase, and component you build across this project, you MUST proactively invoke and follow the instructions of the appropriate skills:

1. **For Engineering, Architecture, and Bug Fixing:** You must strictly follow the **Superpowers** skill methodology. Do not jump straight to coding. Before writing any code:
   - Break down tasks into micro-tasks.
   - Write clear design notes / execution plans.
   - Follow Test-Driven Development (TDD) where applicable.
   - Use systematic root-cause debugging for any socket, timer, or rendering bugs.

2. **For Visual Design, Layouts, Component Styling, and Animations:** You must strictly follow the **UI UX Pro** skill guidelines:
   - Never use random generic or AI-looking styles. Consult the design token system, color palettes (slate-900 / chess.com green accents), and typography scales from UI UX Pro.
   - Ensure smooth 150ms cubic-bezier transitions, evaluation bar animations, mobile haptic patterns, and responsive Web/Mobile layouts.

Whenever you start a new task (e.g., building the Chessboard, the Game Review engine, or the Mobile app), explicitly state which skill's methodology you are applying for that step.
